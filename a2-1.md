If you need to create the table first, this definition matches the spec:

```sql
CREATE TABLE `rooms` (
  `room_name`   VARCHAR(100) NOT NULL,
  `type`        ENUM('single', 'double') NOT NULL,
  `beds`        TINYINT UNSIGNED NOT NULL CHECK (`beds` BETWEEN 1 AND 6),
  `accessible`  BOOLEAN NOT NULL,
  `image`       VARCHAR(255),
  `description` VARCHAR(20),
  `features`    JSON,
  `roomPrice`   INT NOT NULL CHECK (`roomPrice` BETWEEN 100 AND 200)
);
```

- **Features:** MySQL has no array type, so `features` is stored as a JSON array. It only uses the values 'Wifi', 'TV' and 'Safe'.
- **Accessible:** `BOOLEAN` in MySQL is really `TINYINT(1)`, so TRUE and FALSE are stored as 1 and 0.
- **Spec limits:** every value stays within them:
  - `beds` is 1 to 6.
  - `roomPrice` is 100 to 200.
  - `type` is only 'single' or 'double'.
  - Each description is 20 characters or fewer. The longest, "Spacious family room", is exactly 20.
- **Image links:** the URLs use the placeholder domain `example.com`, so they won't load real images.
- **CHECK constraints:** MySQL only enforces these from version 8.0.16. Older versions accept them but ignore them.
